VALIDATION

为什么单次留出切分会说谎Why a single hold-out split lies

同一份数据换一个切分点，结论就能反转 —— 所以验证设计要放在看收益之前。 Move the split point and the conclusion flips — so validation design comes before looking at returns.

最常见的做法是把数据切成「训练段 + 测试段」跑一次，测试段表现不错就收工。问题在于测试段只有一段，它的结果强烈依赖你切在哪里；换一个起点，同一组因子可以从有效变成无效。 The usual approach: cut the data into a train block and a test block, run it once, and stop when the test block looks good. But there is only one test block, and its result depends entirely on where you cut. Move the start date and the same factors can go from working to not working.

  1. 切分点数量与重训成本：用滚动窗口（walk-forward）跑多个不重叠的测试窗，看的指标是「多数窗口是否同向」，而不是某一个窗口的峰值。数量越多结论越稳，但重训成本线性上升 —— 我的起步设置是 5 个窗口。 Number of folds vs retraining cost. Run non-overlapping test windows and read the majority direction, not the best window. More windows means a steadier conclusion and linearly rising retraining cost — five is my starting point.
  2. 窗口长度与制度漂移：窗口越长越稳，但会把旧制度混进来；越短越贴近当下，噪声越大。折中做法是固定测试窗长度（例如 6 个月），把训练窗做成扩张窗口，让早期数据自然退出权重。 Window length vs regime drift. Longer windows are steadier but mix in old regimes; shorter windows are noisier but closer to today. A workable compromise: fix the test window (say six months) and let the training window expand so old data fades out naturally.
  3. 多重检验：试过 20 个变体再挑出最好的那个，等于在测试集上做了 20 次选择，最好看的那个大概率是运气。要么事先固定假设，要么按变体数量做一次保守修正（例如 Bonferroni），并把这个过程写进记录。 Multiple testing. Trying twenty variants and keeping the best one means making twenty choices on the test set — the winner is probably luck. Either pre-register the hypothesis or apply a conservative correction (Bonferroni, for instance), and record that you did.

判断标准很简单：换个切分点结论就翻，这条信号就还没资格进组合。 The test is simple: if the conclusion flips when you move the split point, the signal is not ready for a portfolio.

COSTS

交易成本假设如何悄悄改写夏普How cost assumptions quietly rewrite Sharpe

同一组信号，换一套成本假设，夏普可以从 1.2 掉到 0.4 —— 成本不是最后扣的一项，是设计的一部分。 The same signals can go from a Sharpe of 1.2 to 0.4 on different cost assumptions — costs are a design input, not a final deduction.

很多人把成本当成最后减掉的一个数。实际上换手率、点差和冲击成本各自都能单独把一条信号判死刑，而且它们互相不替代。 Costs are often treated as a single number subtracted at the end. In practice turnover, spread and market impact can each kill a signal on their own, and none of them substitutes for the others.

  • 先看换手，再看收益：先算月均单边换手。如果换手超出资金容量能承受的范围，再漂亮的 IC 也没有意义。 Turnover first, returns second. Compute average one-way monthly turnover before looking at performance. If turnover exceeds what the capacity can absorb, a beautiful IC means nothing.
  • 分层建模，别用一个常数：显性成本（佣金、税费）+ 点差（按流动性分档，流动性差的标的给更宽的假设）+ 冲击成本（用成交量占比的平方根近似）。三层分开写，任何一层换成更准的模型都不用推翻整体。 Model in layers, not as one constant. Explicit costs + spread (tiered by liquidity) + impact (roughly the square root of participation rate). Keeping the layers separate means you can replace any one of them without rebuilding everything.
  • 把成本做成区间而不是点估计：给 5–15 bps 这样的区间，看结论在两端是否都成立。只有低成本端成立，就说明这是成本敏感型信号 —— 出路是降换手或换标池，而不是把假设调低。 Use a range, not a point estimate. Test 5–15 bps and check whether the conclusion holds at both ends. If it only survives at the low end, the signal is cost-sensitive: the fix is lower turnover or a different universe, not a friendlier assumption.
  • 在组合层面评估成本：同一批信号，等权、风险平价、带约束的优化，换手差别很大。成本要放在权重方案这一层比较，而不是只看单条信号的换手。 Evaluate at portfolio level. Equal weight, risk parity and constrained optimisation produce very different turnover from the same signals. Compare costs where the weights are decided, not per signal.

一个能通过的检查：把成本假设翻倍，结论是否仍然成立。如果不成立，那条信号卖的是低成本假设，不是预测能力。 One check worth running: double the cost assumption. If the conclusion does not survive, the signal is selling a cheap-cost assumption rather than predictive power.

ALT DATA

把文本变成事件因子Turning text into event factors

文本因子的难点不在抽取，而在回答「它比现有信息多出了什么」。 The hard part of a text factor is not extraction — it is answering what it adds beyond what you already have.

从新闻、公告或社交文本到「事件因子」，链条通常只有四步：抽取、打分、因子化、回测。真正让结果失真的，几乎都在最后一步的比较基准上。 From news, filings or social text to an event factor is usually four steps: extract, score, build the factor, backtest. Most of what goes wrong sits in the comparison you make at the last step.

  • 时间戳是第一个坑：文本的发布时间不等于数据可得时间。用收盘后才出现的新闻去解释当天收益，是最经典的未来函数。做法是把所有时间戳对齐到「下一个可交易时点」。 Timestamps come first. Publication time is not availability time. Explaining today's return with news that appeared after the close is the classic look-ahead error. Align every timestamp to the next tradable point.
  • 情绪分数本身不是因子：一个 -1 到 +1 的分数不带横截面区分度。要先做中性化（去掉市场、行业、规模成分），再看剩下的部分还有没有信息。 A sentiment score is not a factor. A number between -1 and +1 carries no cross-sectional discrimination until you neutralise market, sector and size, then look at what is left.
  • 只认增量：把动量、波动、规模等已有因子回归掉，看残差的 IC 还剩多少。增量接近零，说明这条文本因子只是已有因子的代理，不构成新信息。 Only incremental value counts. Regress out momentum, volatility and size, then look at the residual IC. If the increment is near zero, the text factor is a proxy for something you already had.
  • 留一段完全不碰的样本外：语言分布会漂移，模型在旧语料上学到的词、在新话题上会系统性失准。留最近 6 个月完全不参与调参，是检验它「还在不在工作」的最低成本方式。 Keep a truly untouched sample. Language drifts: a model trained on older text misreads new topics in a systematic way. Holding out the most recent six months from all tuning is the cheapest way to see whether it still works.

结论：文本因子值得做，但它的价值来自「已有数据没有的信息」，而不是把新闻变成数字。 The takeaway: text factors are worth building, but their value comes from information you did not already have — not from turning news into numbers.
