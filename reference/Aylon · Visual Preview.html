01 · Frame

先把问题
说清楚。

研究不是先打开 notebook，而是先定义目标、约束、数据范围和评价标准。

Question · scope · baseline
具体的研究问题，才会产生可比较的结果。
02 · Build

让数据
流动起来。

从文件、文本和表格中提取信息，构建信号、特征和可复现的模型工作流。

Data → model → workflow
可视化：文件卡片收敛为一个可复用的研究对象。
03 · Validate

每个结论
都要过闸。

用 out-of-sample、walk-forward、成本、压力情景和泄漏检查，筛掉漂亮但不稳的结果。

Evidence gate · human check
闸门：绿色代表可以进入下一步，黄色代表需要人工复核。
04 · Decide

输出可以
被接手的东西。

最后交付的不是一张图，而是研究结论、风险归因和别人可以运行的决策材料。
